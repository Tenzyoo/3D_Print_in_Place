## 二、结构与尺寸设计汇总

1. **四级同轴嵌套圆管结构**：
   - 全部 4 个零件均为旋转对称中空圆管（中心对称轴为 $Z$ 轴，$X=0, Y=0$），最内层 4 号管仍保留 $\varnothing 4.40\text{ mm}$ 中心通孔。
   - 收缩状态整体高度：$L_{\text{retracted}} = 116.0\text{ mm}$（满足 $\le 120\text{ mm}$ 要求）。
   - 最大外径：$D_{\max} = 24.0\text{ mm}$（外半径 $12.0\text{ mm}$，满足 $\le 25\text{ mm}$ 要求）。
   - 单级伸展行程：$S = 70.0\text{ mm}$（共 3 个同轴移动副，总伸展行程 $3 \times 70.0 = 210.0\text{ mm}$）。
   - 完全伸展总长度：$L_{\text{extended}} = 116.0 + 210.0 = 326.0\text{ mm}$（满足 $\ge 300\text{ mm}$ 要求），且在完全伸展状态下相邻两级圆管仍保持 **$46.0\text{ mm}$** 的同轴双轴承导向重合长度，保证伸展后刚度与同轴度。

3. **双向防脱限位与防融合结构设计**：
   - **伸展防脱限位（上限位）**：内管底部设有外扩 $1.00\text{ mm}$ 的导向活塞段（$Z = 4.20 \sim 22.50\text{ mm}$，顶面为 $Z = 22.50 \sim 23.50\text{ mm}$ 的 $45^\circ$ 锥形限位肩）；外管顶部设有内缩 $1.00\text{ mm}$ 的限位领口（底面为 $Z = 92.05 \sim 93.05\text{ mm}$ 的 $45^\circ$ 锥形止挡肩）。当内管沿 $+Z$ 伸出 $70.0\text{ mm}$ 时，两 $45^\circ$ 锥肩精确啮合锁止，单侧径向止挡重叠量达 **$0.50\text{ mm}$**（直径方向重叠 $1.00\text{ mm}$），彻底防止伸长过程中分离脱落。
   - **底部防下脱限位（下限位）与打印防融合间隙**：外管底部 $Z = 0 \sim 3.00\text{ mm}$ 设内缩唇口并在 $Z = 3.00 \sim 4.00\text{ mm}$ 以 $45^\circ$ 锥面扩孔；内管活塞底面在 $Z = 3.20 \sim 4.20\text{ mm}$ 以 $45^\circ$ 锥面外扩。打印状态下两相邻 $45^\circ$ 锥面之间留有 **$0.70\text{ mm}$ 轴向间隙、$0.495\text{ mm}$ 三维法向间隙**，既避免打印过程层间融合，又防止圆管向 $-Z$ 方向滑出。

## 三、打印方向与切片工艺说明

- **打印方向**：**垂直立式打印（圆管中心轴平行于打印机 $+Z$ 轴，底面平铺于热床 $Z = 0$ 平面）**。
- **为什么采用该姿态**：
  1. 4 根嵌套圆管的底面（$Z = 0$）全部直接贴合构建平台，首层同时稳固着床，无任何悬空零件。
  2. 所有限位台阶与直径过渡处均严格采用 **$45^\circ$ 锥面**（$\Delta r / \Delta z = 1.0$），完全处于 FDM 无支撑自承重角度范围内。
  3. 活动间隙内无需任何支撑材料，开启自动支撑或关闭支撑均可直接一体打印完成。
  4. 实机打印较高细圆管时，若热床附着力一般，可在切片软件外围开启外侧 Brim（仅接触 1 号管外底沿，或者对底部开启微量 Brim 后轻刮去除），不影响圆管内部滑动。

## 四、实际完成的几何与切片验证结果

### 1. 网格拓扑与尺寸完整性检查（`trimesh` & `prusa-slicer --info`）
- **水密流形检查**：`model.stl` 及 `parts_1.stl`～`parts_4.stl` 全部为 `watertight = True`、`manifold = yes`，法向朝外，零退化面、零自交。
- **独立连通域检查**：`model.stl` 包含 **4 个完全独立的闭合实体连通域**（`number_of_parts = 4`），4 个零件体积之和为 $33759.23\text{ mm}^3$，与 `model.stl` 总体积 $33759.22\text{ mm}^3$ 完全一致，且处于完全相同的世界坐标系与收缩姿态。
- **外形包络尺寸**：$X \in [-12.00, 12.00]\text{ mm}$，$Y \in [-12.00, 12.00]\text{ mm}$，$Z \in [0.00, 116.00]\text{ mm}$，最大外径 $24.00\text{ mm} \le 25\text{ mm}$，收缩长度 $116.00\text{ mm} \le 120\text{ mm}$。

### 2. 径向配合间隙截面检查（`trimesh.section`）
在底部唇口段（$Z = 1.5\text{ mm}$）、下部活塞导向段（$Z = 10.0, 20.0\text{ mm}$）及上部领口导向段（$Z = 95.0, 105.0, 115.0\text{ mm}$）对相邻圆管截取二维水平截面，实测单侧径向间隙：
- 1号管内壁 vs 2号管外壁：$0.4971 \sim 0.4995\text{ mm}$（设计值 $0.50\text{ mm}$，满足 $0.4 \sim 0.6\text{ mm}$）
- 2号管内壁 vs 3号管外壁：$0.4979 \sim 0.4996\text{ mm}$（设计值 $0.50\text{ mm}$，满足 $0.4 \sim 0.6\text{ mm}$）
- 3号管内壁 vs 4号管外壁：$0.4988 \sim 0.4998\text{ mm}$（设计值 $0.50\text{ mm}$，满足 $0.4 \sim 0.6\text{ mm}$）

### 3. 运动学行程与防脱限位三维布尔碰撞检查（`manifold3d`）
对每一级相邻圆管 $(i, i+1)$ 沿运动轴 $[0, 0, 1]$ 进行三维网格布尔交集测试：
- **有效滑动行程区间 $s \in [0.00, 70.00]\text{ mm}$**：在 $s = 0, 10, 35, 60, 69.5, 70.0\text{ mm}$ 全行程内，相邻圆管三维布尔交集体积恒为 **$0.000\text{ mm}^3$**，滑动过程无任何干涉。
- **上限位防脱验证 $s > 70.05\text{ mm}$**：当 $s = 70.10\text{ mm}$ 时布尔干涉体积立即变为正值（三对圆管分别为 $1.531, 1.107, 0.683\text{ mm}^3$），在 $s = 71.00\text{ mm}$ 时干涉体积达 $29.087, 21.032, 12.977\text{ mm}^3$，证明顶部 $45^\circ$ 限位领口可靠阻止内管脱出。
- **下限位防脱验证 $s < -0.70\text{ mm}$**：当 $s = -0.80\text{ mm}$ 时布尔干涉体积变为正值（$3.062, 2.214, 1.366\text{ mm}^3$），证明底部 $45^\circ$ 限位座可靠阻止内管向下脱出。
- **完全伸展总长验证**：按 `joints.json` 中三级行程累加（$70 + 70 + 70 = 210\text{ mm}$），整体 $Z$ 轴跨度为 $[0.00, 326.00]\text{ mm}$，总长度 **$326.00\text{ mm} \ge 300\text{ mm}$**。

### 4. PrusaSlicer 切片与 G-code 逐层验证
使用 `/opt/slicer/p1s_pla_0.20mm_nosupport.ini` 与 `/opt/slicer/p1s_pla_0.20mm_autosupport.ini` 对 `model.stl` 进行实际命令行切片并解析生成的 G-code：
- **总层数**：共 **580 层**（首层 $Z = 0.20\text{ mm}$，顶层 $Z = 116.00\text{ mm}$，层高 $0.20\text{ mm}$）。
- **零支撑依赖验证**：在开启自动支撑（`p1s_pla_0.20mm_autosupport.ini`）与关闭支撑（`p1s_pla_0.20mm_nosupport.ini`）两种配置下，生成的 G-code 中支撑路径（`Support material` / `Support material interface`）数量均为 **0**，圆管活动间隙内无任何支撑材料。
- **全层同心独立性验证**：逐层扫描全部 580 层的挤出中心线半径分布，每一层均存在 **4 组完全独立的同心圆环挤出轨迹**，相邻圆管外轮廓中心线最小径向间距为 $0.880\text{ mm}$（扣除 $0.42\text{ mm}$ 挤出线宽后实际物理气隙约 $0.46\text{ mm}$），全高 580 层无任何跨间隙桥接或融合。
