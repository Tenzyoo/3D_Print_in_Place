## 结构

- **关节**（左右各 1 个，轴线 ∥ Z，位于 (12, ±12.5, 0)）：躯干上的竖直销轴通过一条 2.4 mm 宽的连接筋连到胸部；翅膀根部是一个 C 形轴环（包角 246°，开口朝躯干、让开连接筋）。
  - 销轴 r = 3.5 mm，轴孔 r = 4.0 mm，**单侧径向间隙 0.5 mm**，每一层都一样（截面实测）。
  - 轴向防脱：销轴底部有 50° 锥形外扩（r 4.7），挡住翅膀向 −Z 脱出；顶部是 50° 沉头（r 4.9），挡住 +Z 方向。轴孔是销轴轮廓径向外移 0.5 mm 得到的，锥面处竖直间隙 0.6 mm（3 层）。
  - C 环开口弦长小于销轴直径，翅膀也不能侧向拔出。
- **其它活动面间隙**：
  - C 环外圆与躯干切口：0.6 mm。
  - 连接筋与 C 环端面：±30° 时 ≥ 0.6 mm。
  - 翅面与躯干：≥ 0.8 mm。翅膀轮廓已减去"躯干在 ±34° 范围内相对翅膀扫过的区域外扩 0.8 mm"。
- **装饰**：翅脉、中室、眼斑、缘点、翅缘围边，均在翅面顶部凸起 0.8 mm。它们只在翅膀上表面，不与任何活动面相邻。
- **外接尺寸（中立）**：94.8 × 98.8 × 11.0 mm（≤ 120 × 100 × 30）。

## 打印方向与设置

- 按模型原姿态平放：z = 0 面贴床，Z 朝上，三件同床一次打印，**不加支撑、不加 brim**。
- PLA，0.4 mm 喷嘴，0.2 mm 层高（`/opt/slicer/p1s_pla_0.20mm_nosupport.ini`）。共 55 层，预计 1 h 21 min，耗丝约 3.58 m（≈ 10.7 g）。
- 所有朝下的面都是 50° 锥面，离竖直不超过 40°；躯干球面与复眼下锥同样满足。关节间隙内不存在悬空平面，因此不依赖支撑。
- 打印后先单独小幅来回拨动每片翅膀，掰开首层可能的轻微粘连。
