# 一体化 3D 打印四级伸缩棒（Print-in-Place 4-Stage Telescopic Rod）设计、打印方向与验证说明

## 1. 交付文件清单

所有交付文件均位于 `/app/output/` 目录下，单位均为 `mm`，坐标系与姿态完全一致：

- `/app/output/model.scad`：完整参数化 OpenSCAD 源代码（支持通过 `part_id` 导出组装模型或单个零件，通过 `extension` / `extend_factor` 控制各级伸展状态）。
- `/app/output/model.stl`：收缩状态下的完整四级嵌套模型（4 个相互独立的闭合流形网格）。
- `/app/output/parts/parts_1.stl`：第 1 级圆管（最外层基座圆管/握柄）。
- `/app/output/parts/parts_2.stl`：第 2 级圆管（次外层滑动圆管）。
- `/app/output/parts/parts_3.stl`：第 3 级圆管（次内层滑动圆管）。
- `/app/output/parts/parts_4.stl`：第 4 级圆管（最内层顶端滑动圆管）。
- `/app/output/joints.json`：声明相邻圆管的运动轴、伸缩行程、配合间隙与双向防脱限位关系。
- `/app/output/README.md`：本说明文档（打印方向及几何与切片检查报告）。

## 2. 打印方向与 FDM 工艺设计说明

### 2.1 打印方向（Print Orientation）
- **打印朝向**：沿 **+Z 轴竖直向上立式打印**（中心轴为 `Z` 轴 `[0, 0, 1]`，底面平贴打印平台 `z = 0`）。
- **无需旋转或调整**：`model.stl` 与 `parts/parts_1.stl`–`parts_4.stl` 在导出时已直接处于最佳打印姿态（`min_z = 0.000 mm`，`max_z = 115.000 mm`）。
- **底面首层附着设计**：4 根圆管在 `z = 0` 处均直接接触热床平台，每根圆管底面均为径向壁厚 `1.20–2.20 mm` 的完整圆环（3–5 圈喷嘴走线），首层附着面积充足且无任何悬空零件。

### 2.2 免支撑自承重结构（Support-Free Overhang Design）
- 所有内外防脱限位台阶均采用 **锥面斜坡过渡**（径向凸起高度 `stop_lip_height = 1.00 mm`，轴向斜坡高度 `ramp_height = 1.50 mm`）。
- 悬垂面与竖直方向（Z 轴）夹角为 $\arctan(1.0 / 1.5) = 33.69^\circ$（即与水平面夹角 $56.31^\circ$），远优于 FDM PLA 在 `0.4 mm` 喷嘴、`0.2 mm` 层高下的 $45^\circ$ 免支撑阈值。
- 因此圆管之间的活动间隙及内部腔体**完全不需要任何支撑材料**。

### 3.3 配合间隙与双向防脱限位机制
1. **双导承同轴滑动配合面（单侧径向间隙 `0.50 mm`）**：
   - **下导承副**：内管底部外凸活塞段（`z ∈ [4.5, 22.5] mm`，长 `18.0 mm`）在外管主内壁（`z ∈ [4.0, 92.0] mm`）内滑动，单侧径向间隙为：
     - `parts_1` / `parts_2`：`10.80 - 10.30 = 0.50 mm`
     - `parts_2` / `parts_3`：`8.10 - 7.60 = 0.50 mm`
     - `parts_3` / `parts_4`：`5.40 - 4.90 = 0.50 mm`
   - **上导承副**：内管主外壁（`z ∈ [24.0, 115.0] mm`）在外管顶部内缩导向颈（`z ∈ [93.5, 115.0] mm`，长 `21.5 mm`）内滑动，单侧径向间隙为：
     - `parts_1` / `parts_2`：`9.80 - 9.30 = 0.50 mm`
     - `parts_2` / `parts_3`：`7.10 - 6.60 = 0.50 mm`
     - `parts_3` / `parts_4`：`4.40 - 3.90 = 0.50 mm`
   - 上下两组同轴圆柱导承副在整个伸缩行程 `[0, 70.0] mm` 内始终同时保持啮合，在完全伸展状态下相邻两管仍有 `45.0 mm` 的轴向重叠导向段，保证伸展后同轴度与结构刚度。
2. **顶部伸展防脱限位结构**：
   - 当内管沿 `+Z` 伸出至 `70.25 mm` 时，内管底部活塞环上锥面（`z_local ∈ [22.5, 24.0] mm`）与外管顶部限位颈下锥面（`z ∈ [92.0, 93.5] mm`）精确贴合锁死。
   - 单侧径向防脱重叠量为 `0.50 mm`（直径方向重叠 `1.00 mm`），机械阻挡内管从顶部脱出。
3. **底部回缩防脱限位与打印防融合间隙**：
   - 外管底部内壁（`z ∈ [0.0, 2.5] mm`）设有底部限位内环，并在 `z ∈ [2.5, 4.0] mm` 处以 $33.69^\circ$ 锥面过渡至主内孔；内管底部外凸活塞环则在 `z ∈ [3.0, 4.5] mm` 处以平行锥面展开。
   - 在收缩打印状态（`dz = 0`）下，两平行锥面之间留有 `0.50 mm` 轴向偏移与 `0.50 mm` 径向间隙，对应法向三维间隙为 `0.693 mm`，有效防止打印首层及底部限位区域粘连融合；同时向 `-Z` 方向仅移动 `1.25 mm` 即触发底部防脱限位，避免内管从底部滑出。

## 4. 实际完成的几何、运动学与切片检查结果

### 4.1 网格流形性与尺寸检查（`trimesh` & `prusa-slicer --info`）
- **流形性检查**：`model.stl` 及 `parts_1.stl`–`parts_4.stl` 全部满足 `is_watertight = True`、`is_winding_consistent = True`、`manifold = yes`。
- **连通分量检查**：`model.stl` 包含严格独立的 `4` 个连通网格体（`body_count = 4`），总体积为 `31742.16 mm³`，与 4 个独立零件体积之和（`11531.99 + 9957.97 + 6854.69 + 3397.51 = 31742.17 mm³`）完全一致。
- **包围盒检查**：`min = [-12.0, -12.0, 0.0] mm`，`max = [12.0, 12.0, 115.0] mm`，外径 `24.0 mm <= 25.0 mm`，收缩长度 `115.0 mm <= 120.0 mm`。
- **三维表面最小距离检查**：通过 `scipy.spatial.cKDTree` 对相邻圆管表面密集采样点云测算，收缩状态下 `parts_1`/`parts_2`、`parts_2`/`parts_3`、`parts_3`/`parts_4` 之间的全局最小三维表面距离均为 **`0.500 mm`**，无任何接触或融合。

### 4.2 运动学滑动与防脱碰撞检查（`manifold3d` 布尔交集验证）
对 3 个关节（`joint_1_2`、`joint_2_3`、`joint_3_4`）沿轴向 `[0, 0, 1]` 进行平移布尔求交测试：
- **正常滑动区间 `dz ∈ [-1.25, 70.25] mm`**（覆盖完整额定行程 `[0.0, 70.0] mm`）：3 组相邻圆管的布尔交集体积恒为 **`0.000 mm³`**，证明全程滑动顺畅无干涉。
- **伸展超程防脱验证（`dz > 70.25 mm`）**：
  - 在 `dz = 70.50 mm` 处，三级关节布尔干涉体积分别为 `7.890 mm³`、`5.770 mm³`、`3.651 mm³`；
  - 在 `dz = 71.00 mm` 处，布尔干涉体积增至 `23.671 mm³`、`17.311 mm³`、`10.952 mm³`；
  - 在 `dz = 75.00 mm` 处，布尔干涉体积达 `149.913 mm³`、`109.637 mm³`、`69.362 mm³`，证明顶部防脱限位结构可靠阻挡分离。
- **回缩超程防脱验证（`dz < -1.25 mm`）**：在 `dz = -1.50 mm` 与 `-2.00 mm` 处同样产生显著正布尔交集体积，证明底部防脱限位同样有效。

### 4.3 PrusaSlicer 切片与无支撑检查
使用 `/opt/slicer/` 下的 Bambu Lab P1S（`0.4 mm` 喷嘴、`0.20 mm` 层高、PLA）配置对 `/app/output/model.stl` 进行实际命令行切片验证：
- **无支撑配置（`p1s_pla_0.20mm_nosupport.ini`）**：成功切片，共 **575 层**（`115.0 mm / 0.20 mm`），耗材长度 `13308.56 mm`，支撑路径段数 `0`。
- **自动支撑配置（`p1s_pla_0.20mm_autosupport.ini`）**：成功切片，共 **575 层**，耗材长度同样为 `13308.56 mm`，生成的支撑路径段数（`;TYPE:Support`）为 **`0`**，验证了模型在开启自动支撑时也不会在管间间隙生成任何支撑材料。
