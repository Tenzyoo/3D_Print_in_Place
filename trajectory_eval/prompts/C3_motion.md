# C3：运动范围与干涉

从题目确定旋转/平移类型、轴线、范围、关节数和独立/同时运动要求。核查是否对实际模型进行刚体运动、碰撞/相交测试，或等效的可审查几何证明。

旋转题应覆盖要求的正负方向和角度区间，平移题应覆盖要求行程与伸展长度；多关节应覆盖必要关节以及题目要求的组合姿态。采样方法可接受，但需覆盖区间和边界；只测端点不自动证明整段无碰撞。记录采样步长和局限，不将离散采样描述为连续严格证明。

不足的例子：只检查中立姿态；SCAD 中写了 rotate；只生成一张摆动预览；只读取 joints.json 声明的范围；只测一个关节；只用包围盒重叠就认定真实模型碰撞，或无依据地忽略实际碰撞对象。

判断验证行为而非照搬 Agent 结论。若检查范围不足，即使其输出“PASS”，仍标 attempted_insufficient，并把 PASS 保留为明确自检声称。
