# 四级一体打印伸缩棒：打印方向与检查说明

## 文件
| 文件 | 内容 |
|---|---|
| `model.scad` | 参数化源码（`part=0` 为整体，`part=1..4` 为单根管） |
| `model.stl` | 收缩状态（即打印状态）整体模型，4 个互不接触的实体 |
| `parts/parts_1..4.stl` | 4 根管，1 = 最外管，4 = 最内管，与 `model.stl` 同一坐标系 |
| `joints.json` | 3 个移动副：轴向、行程、限位关系 |
| `section.png` | 轴向剖面图：收缩状态、伸展状态、顶部细节 |
| `checks/` | 检查脚本与日志（`geom_check.*`、`gcode_check.*`） |

## 结构
- 所有管子底面都在 z=0。内层管依次加长 4 mm（107/111/115/119 mm），伸出的部分可以用手指捏住拉出。
- 外管 Ø25 mm，壁厚 1.2 mm。各管外径依次为 25 / 18.8 / 12.6 / 6.4 mm，最内管内径 4 mm。
- **拉出限位**：内管底部有一圈高 18 mm 的套环，在外管内孔中滑动；外管顶部有一圈向内的限位唇。两者都做成 45° 锥面，伸到底时锥面贴合，径向搭接 0.9 mm。
- **压入限位**：内管顶部有一圈 45° 外凸缘，打印时它与外管顶面之间留有 0.6 mm 轴向间隙（3 层）。往下压 1.1 mm 后凸缘碰到外管顶面，管子不会从底部滑出。
- **间隙**：两处滑动配合面（套环外壁对外管内孔、内管管身对限位唇）单侧径向间隙均为 **0.5 mm**。打印状态下各限位面之间的最小间隙也是 0.5 mm（不为零）。
- 底部边缘做了 0.4 mm×45° 倒角，抵消首层"象脚"，首层上的实际间隙约 1.1 mm。

## 打印方向
**直立打印**：轴线竖直，z=0 端贴热床，按收缩状态一次打印完成。不加支撑，不需要组装。

4 根管各自从热床长起。所有悬垂面都是 45° 锥面（下唇锥面、凸缘下表面、底部倒角），没有水平悬空面。管与管之间的间隙全程是竖直的空槽，不需要支撑。打印完成后，依次捏住各管顶部凸缘拉出即可（如有轻微粘连，先转动一下）。

## 已完成的检查（日志见 `checks/`）
**几何检查**（`geom_check.py`，基于导出的 STL，使用 trimesh + manifold3d + shapely）
- 每个零件都是水密的单一实体；`model.stl` 由 4 个实体组成，体积等于各零件之和（28695.5 mm³）。外形尺寸 25×25×119 mm。
- 打印状态下任意两根管的布尔交集体积都为 0。
- 轴向剖面上相邻两管最小间隙为 0.500 mm；套环与内孔、限位唇与管身的径向间隙实测均为 0.500 mm。
- 运动扫描：内管沿 Z 每 0.5 mm 检测一次干涉，结果如下。

  | 移动副 | 行程范围（mm） |
  |---|---|
  | 1-2 | −1.11 … +86.91 |
  | 2-3 | −1.11 … +90.91 |
  | 3-4 | −1.11 … +94.91 |

  行程内无干涉，与设计值一致。超出两端限位后都会产生干涉（即被挡住）；内管横向偏移 ±0.49 mm 的最坏情况下也同样被挡住，管子不会脱出。
- 完全伸展：4 根管两两无干涉，总长 **391.6 mm**（≥300），每一级伸到底时套接长度为 20.1 mm。
- 悬垂分析：朝下的面最平也是 45°，水平悬空面数量为 0。

**切片检查**（PrusaSlicer 2.7.2，`/opt/slicer` 中的 P1S PLA 0.2 mm 配置）
- `nosupport` 配置：595 层，耗时约 4 h 16 min，耗材 27.3 cm³。
- `autosupport` 配置（自动支撑打开，阈值为自动）：**没有生成任何支撑**（G-code 中没有 `Support material`）。
- 逐层解析 G-code（`gcode_check.py`）：按线宽计算挤出线条外缘的径向位置，每层相邻管之间都保留独立间隙。最小间隙 0.453 mm（z=9.0），首层 1.07 mm。两处桥接填充（z=110.2 和 114.2）位于管 2、管 3 顶部实心区域内部，没有跨越管与管之间的间隙。

## 注意事项
- 0.5 mm 间隙下，伸展到底时每一级约有 2–3° 的晃动，这是间隙要求带来的固有结果。
- 若打印机挤出偏多，可以把 `clr` 调到 0.6；若希望更紧，可调到 0.4，然后重新导出。
