# 一体打印可活动小蛇：打印方向与检查说明

## 文件
| 文件 | 内容 |
|---|---|
| `model.scad` | 参数化源码（`-D part=N` 导出单个零件，N=1 头部，2–6 身体 1–5） |
| `model.stl` | 中立伸直姿态完整模型（6 个互不相连的实体） |
| `parts/parts_1.stl … parts_6.stl` | 头部、身体 1–5，与 `model.stl` 同坐标系、同姿态 |
| `joints.json` | 零件、5 个关节（父/子零件、轴、原点、运动范围、验证结果） |
| `verify.py` → `verify_report.json` | 几何/运动检查 |
| `slice_check.py` → `slice_report.json` | 基于 G-code 的切片检查 |
| `model_P1S_PLA_0.2mm_autosupport.gcode` | PrusaSlicer 切片结果（自动支撑配置） |

重新生成：`openscad -o model.stl model.scad`；`openscad -D part=N -o parts/parts_N.stl model.scad`；然后运行 `python3 verify.py`，以及 `python3 slice_check.py <gcode>`。

## 结构
- 坐标系：头部朝 +X，Z 向上，底面在 z=0。外接尺寸为 **155.1 × 26.0 × 14.0 mm**（上限 160×50×40）。
- 关节 i 位于 (x = −22·(i−1), y = 0)，轴为 +Z，共 5 个。
- 关节形式为“轴套 + 双锥凸环销轴”：
  - 前一节尾部有竖直轴套环（外径 R10）。轴孔半径 4.5，中部有 45° 双锥环槽，最大半径 6.5，槽口朝后。
  - 后一节前端有竖直销轴（半径 4.0），中部有 45° 双锥凸环（半径 6.0），通过 4 mm 宽的颈部连到本体。
  - 凸环卡在环槽内，所以沿 Z 轴向上、向下都不能脱出（**轴向防脱**）。凸环同时比槽口宽，所以销轴也不能从槽口水平拔出。
- 间隙：
  - 销轴与轴孔的单侧径向间隙为 **0.5 mm**（圆柱段和凸环段都是 0.5；锥面法向 0.5，竖直方向 0.71）。
  - 颈部与槽口之间、相邻两节本体之间的间隙为 **0.6 mm**。这些间隙是把后一节在 ±30° 内扫掠一遍，再外偏 0.6 mm 得到的，所以整个运动范围内都保持间隙。
  - 首层整体内缩 0.2 mm，用来抵消象脚；销轴底部有 0.4 mm 的 45° 倒角。
- 限位：颈部碰到槽口侧壁时就是机械限位，约 ±33°。

## 打印方向与设置
- **按 STL 原姿态直接平放打印**：底面（z=0）贴床，Z 轴竖直，关节轴与 Z 平行。6 个零件同时打印，不需要装配。
- PLA，0.4 mm 喷嘴，0.2 mm 层高，**不加支撑**（用 `p1s_pla_0.20mm_nosupport.ini` 即可）。
- 关节内所有朝下的表面都是 45° 锥面（销轴凸环下锥面、轴孔环槽上锥面），其余面都是竖直面或朝上的面，所以间隙内不需要支撑。
- 打印完成后，左右掰动每一节，把首层可能出现的轻微粘连掰开即可。

## 已完成的检查（结果见 `verify_report.json` 和 `slice_report.json`）
1. **网格**：6 个零件都是水密的单一实体。`model.stl` 由 6 个实体组成，体积等于各零件之和（37 887.9 mm³）。PrusaSlicer `--info` 结果为 manifold = yes。
2. **中立姿态干涉**：用 manifold3d 对 15 组零件两两求交，交集体积全部为 0。
3. **逐层间隙**（网格截面，每 0.2 mm 一层）：相邻关节零件之间的最小 XY 间隙为 0.50 mm。在 z = 1、2.5、7、12 mm 处测得的销轴径向间隙均为 0.50 mm。
4. **运动**：
   - 每个关节单独转动（后面整条链跟着转），步长 1°。在 **±33°** 内无干涉，满足 ≥ ±25° 的要求。
   - 在声明范围 ±30° 内又按 0.5° 步长检查了父/子零件，交集为 0。
   - 组合姿态（全部 +25°、−25°、+30°、−30°，以及 ±25° 交替）下，所有零件两两之间都没有干涉。
5. **防脱**：
   - 子零件沿 ±Z 平移 0.75 mm 即与父零件干涉，说明轴向是锁住的。
   - 子零件向后（−X）平移 0.95 mm 即干涉，说明销轴不能从槽口水平拔出。
6. **悬垂**：比 45° 更平的朝下面只出现在 z = 0.2 mm 处，是 0.2 mm 宽的首层内缩台阶。z > 0.2 mm 的部分没有这类表面。
7. **切片**（PrusaSlicer 2.7，P1S/PLA/0.2 mm 配置）：
   - 自动支撑配置和无支撑配置都能正常切片，共 70 层，约 17.5 cm³，预计打印 2 h 03 min。
   - **自动支撑配置也没有生成任何支撑**（G-code 中没有 Support material 类型的挤出）。
   - 解析 G-code 后，把每条挤出线按实际线宽膨胀，再逐层计算相邻关节零件实际沉积材料之间的最小距离。5 个关节分别为 0.472–0.476 mm，没有任何一层发生接触。
   - 出现的 Bridge infill 只在 z = 11.6 和 13.2 mm，是零件内部稀疏填充上方的实心层，不在关节间隙里。已核对：这些挤出点全部落在下一层零件截面之内，离截面边界至少 0.69 mm。

## 限制
以上都是几何和切片层面的验证，没有做实物打印。实际能否转动，取决于打印机的精度和首层压得多紧。如果首层压得过紧，第一次掰动时可能需要稍微用点力。
