# 三节一体化打印折叠尺：打印方向与检查说明

## 文件
| 文件 | 内容 |
|---|---|
| `model.scad` | 参数化源码（`part=0` 整体，`part=1..3` 单段） |
| `model.stl` | 0° 完全展开的整体模型（3 个互不接触的实体） |
| `parts/parts_1.stl` … `parts_3.stl` | 各尺段，与 `model.stl` 同坐标系、同姿态 |
| `joints.json` | 关节定义：父/子段、轴线、位置、0–180° 范围、折叠方向 |
| `checks/` | 检查脚本、报告（`*_report*.json`）和关节剖面图 `joint_section.png` |
| `slice/` | PrusaSlicer 2.7 生成的 G-code 和日志（有支撑/无支撑两套配置） |

重新生成：
```
openscad -o model.stl model.scad
openscad -D part=1 -o parts/parts_1.stl model.scad   # 2、3 同理
```

## 结构
- 每段主体 40 × 12 × 5 mm。0° 时三段沿 X 轴排成一条直线：x = 0–40、40.5–80.5、81–121，端面间隙 0.5 mm。
- **J1**：轴线 (40.25, 6.4)，方向 +Z，折叠方向为 CCW。parts_2 摆到 parts_1 的 +Y 侧。
- **J2**：轴线 (80.75, −6.4)，方向 −Z（即俯视顺时针 CW）。parts_3 摆到 parts_2 的 −Y 侧。
- 两个关节的轴线放在尺身相反两侧、距侧边 0.4 mm 处，所以折叠后呈 Z 字形，三段并排，每两段之间间隙 0.8 mm。两个关节可以各自独立、也可以同时在 0–180° 内转动。
- 关节区比尺身宽：在侧边外伸出约 5 mm 的凸耳（总宽 22.2 mm）。这部分属于关节结构，不算尺身主体。
- **关节结构**（编号小的段是父段，见 `checks/joint_section.png`）：
  - **父段**：Ø4 圆柱销直接立在热床上，底部有 Ø6.6、50° 的锥形防脱脚。销顶通过一块"桥板"与父段尺身相连，桥板最薄处 1.33 mm。
  - **子段**：环形轴套，也立在热床上。内孔底部是与防脱脚配合的 50° 锥面，顶面是不对称人字形（50°）。
  - **轴向防脱**：子段向上会顶到桥板，向下会被锥形脚挡住。实测轴向只能移动 ±0.62 mm，再多就会实体接触。
- 0° 和 180° 两端外侧各有实体止挡，由尺身互相接触形成（约 −2.3° 和 181.1°）。

## 间隙（设计值）
| 位置 | 间隙 |
|---|---|
| 销轴与轴孔（圆柱段） | **单侧径向 0.5 mm** |
| 锥形脚 / 人字面等 50° 斜面 | 法向 0.4 mm（水平 0.52，竖直 0.62） |
| 轴套外圆与父段让位面 | 径向 0.5 mm |
| 0° 时相邻端面 | 0.5 mm |
| 180° 时并排侧面 | 0.8 mm |

## 打印方向与设置
- **打印方向**：按模型原样放置，z = 0 面贴热床、刻度面朝上，关节轴竖直（沿 Z）。模型不需要旋转，直接整体导入 `model.stl` 一次打印。
- 材料与参数：PLA，0.4 mm 喷嘴，0.2 mm 层高，用 `/opt/slicer/` 的配置。
- **不需要支撑。**
- **不要加 brim**：brim 会填进零件之间 0.5 mm 的底层间隙，把零件粘在一起。
- 首层如果象脚明显，可以设 `elefant_foot_compensation = 0.1`。
- 打印完成后轻轻来回转动每个关节，让它们松开。

## 已完成的检查
以下结果都由 `checks/` 里的脚本实际运行得出。没有做实物打印验证。

**网格**（`check_motion.py`、`prusa-slicer --info`）
- 3 个零件都是封闭流形，各自为单一实体。
- 体积分别为 2425.8、2459.4、2423.9 mm³。
- `model.stl` 由 3 个实体组成，总体积 7309.1 mm³，等于三个零件体积之和。
- 包围盒 121 × 22.2 × 5 mm。

**运动干涉**（`check_motion.py`，结果在 `motion_report.json`）
- 按 joints.json 的运动链计算，每 2° 扫描一次：
  - J1 单独转动 0–180°；
  - J2 单独转动 0–180°；
  - J1 × J2 全网格，共 91 × 91 = 8281 个姿态。
- 所有姿态下，任意两段之间的相交体积都是 **0**。
- 最小间隙 **0.399 mm**，出现在 50° 斜面处，即设计的 0.4 mm 法向间隙（差值来自网格离散化）。
- 0°/0°、180°/180°、90°/90° 等姿态下，最小间隙同样为 0.399–1.0 mm。
- 超出范围检查：转到 −4° 或 184° 时会发生干涉，说明两端外侧确有实体止挡。

**轴向防脱**（`check_axial.py`）
- 在 0°、90°、180° 三个角度下，把子段沿 ±Z 平移。
- 两个关节、两个方向都在移动 0.65 mm 时与父段发生干涉，所以子段不能沿轴线脱出。

**截面逐层检查**（`check_slices.py`，按 0.2 mm 层高切 25 层）
- 同一层内不同零件截面之间的最小间隙为 **0.50 mm**。
- 每个零件相对自身下一层，悬出超过 0.21 mm（相当于 45°）的面积为 **0 mm²**。也就是说，任何零件都没有悬空在另一个零件上或悬空在空中的区域。

**PrusaSlicer 2.7 实际切片**（`slice/`、`slice_report_*.json`）
- 两套配置切片都成功，均无 "print stability" 警告。估计打印时间约 36 分钟，耗材约 1.8 m。
- **自动支撑配置（threshold 0）下生成的支撑为 0 条**，G-code 运动指令与无支撑配置完全相同。
- 解析 G-code，把每条挤出线按线宽展开成面域后检查：
  - 没有任何挤出线进入另一个零件；
  - 同一层内不同零件的实际挤出之间，最小间隙 **0.43 mm**，因此不会熔连。
- 有 8 段 bridge infill 不完全在自身下一层之上。它们都位于父段桥板人字顶脊的合拢处（z = 3.8 mm），每段悬空面积不超过 0.12 mm²，离下方其他零件的水平距离不小于 1.17 mm（竖直方向 0.56 mm）。这只是两侧斜面生长合拢时留下的窄缝，不是跨越关节间隙的桥接。

## 说明
- 早期版本的关节在 PrusaSlicer 中出现过 "Low bed adhesion" 稳定性提示，原因是销轴一侧悬挑过长。之后调整了参数：防脱脚加大到 r = 3.3，轴套顶脊移到靠近轴孔一侧（`ridge_dr`），提示随之消失。
- 尺面刻度为 5 mm 间隔的刻槽（深 0.6 mm），会自动避开关节区。刻度按每段各自计数，因为相邻段之间有 0.5 mm 间隙。
