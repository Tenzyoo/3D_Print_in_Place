# 三节一体打印折叠尺

## 1. 文件说明

| 文件 | 内容 |
|---|---|
| `model.scad` | 参数化 OpenSCAD 源文件，默认输出完整装配体 |
| `model.stl` | 0°完全展开状态的完整模型，3 个独立刚体互相咬合 |
| `parts/parts_1.stl` | 第 1 节（左端），含关节 1 的整体销轴 |
| `parts/parts_2.stl` | 第 2 节（中间），左端为关节 1 的捕获孔，右端为关节 2 的整体销轴 |
| `parts/parts_3.stl` | 第 3 节（右端），含关节 2 的捕获孔 |
| `joints.json` | 两关节的父/子零件、轴线、0°位置、0°～180°范围、折叠方向与运动学 |
| `validate_motion.py` | 可选复现脚本：按 `joints.json` 对零件做布尔干涉检查 |
| `collision_check.json` | 本次 2° 网格运动检查结果 |
| `README.md` | 本说明 |

`parts/` 下的三个 STL 与 `model.stl` 使用完全相同的世界坐标和同一 0°姿态；三个零件直接拼接即为 `model.stl`。

## 2. 几何与结构

- 每节主体：长 **40.0 mm**、宽 **12.0 mm**、厚 **5.0 mm**。
- 三节主体在 0°时沿 +X 排成一条直线，相邻主体端面留 **0.5 mm** 间隙。
- 主体长度不含两端关节凸耳；三节主体加两个端面间隙后，模型总长 **121.0 mm**。
- 两个关节都是**竖直销轴关节**，轴线平行于 Z；折叠运动完全在 XY 平面内。
- 关节 1 轴线：`(0.0, +6.3, 0)`，位于第 1/2 节上边缘外侧 0.3 mm。
- 关节 2 轴线：`(40.5, -6.3, 0)`，位于第 2/3 节下边缘外侧 0.3 mm。

两个关节的轴线分别位于尺段宽度方向的两侧（上、下），这是为了在 180°/180° 同时折叠时让三节主体并排叠放而不互相扫掠。第 1 节只有关节 1 的销轴；第 2 节左端是关节 1 的捕获孔、右端是关节 2 的销轴；第 3 节只有关节 2 的捕获孔。因此模型是 **3 个独立刚体、2 个转动关节**。

## 3. 关节、间隙和轴向防脱

每个关节采用“连续整体销轴 + 上下挡环 + 中间捕获板”的打印一体结构：

- 销轴半径 **1.2 mm**（直径 2.4 mm），轴孔半径 **1.7 mm**（直径 3.4 mm），单侧径向间隙 **0.5 mm**。
- 销轴所在零件在底部和顶部各有一个半径 **3.0 mm** 的挡环（knuckle）。
- 另一零件在中间层有一个内径 **1.7 mm** 的轴承孔；上下层为半径 **3.6 mm** 的沉孔，让挡环以 **0.6 mm** 单侧径向间隙自由转动。
- 中间捕获板被上下挡环夹住：捕获板内径 1.7 mm，挡环半径 3.0 mm，径向重叠 1.3 mm；因此零件不能沿关节轴线直接脱出。
- 挡环与捕获板之间的轴向运动间隙为 **0.4 mm**（上下各 2 层）。
- 关节其他活动面：挡环与沉孔单侧 **0.6 mm**，转动环与让位孔单侧 **0.4 mm**，主体端面 **0.5 mm**。
- 关节间隙内不放任何支撑；所有间隙在切片中保持为空。

Z 向分层（总厚度 5.0 mm）：

| Z 范围 | 关节区域内容 |
|---|---|
| 0.0–1.0 | 销轴零件的底部挡环 r3.0；捕获零件为 r3.6 沉孔 |
| 1.0–1.4 | 0.4 mm 轴向间隙，仅销轴 r1.2 穿过 |
| 1.4–3.6 | 捕获零件的轴承孔 r1.7 与转动环；销轴 r1.2 |
| 3.6–4.0 | 0.4 mm 轴向间隙，仅销轴 r1.2 穿过 |
| 4.0–5.0 | 销轴零件的顶部挡环 r3.0；捕获零件为 r3.6 沉孔 |

## 4. 运动定义

`joints.json` 中的角度均为非负幅值，范围 **0°～180°**：

- **0°**：相邻两节主体共线，即完全展开。
- **180°**：向回折叠到相邻主体并排。
- 关节 1：绕 +Z **逆时针**旋转（从 +Z 看），`fold_sign = +1`。
- 关节 2：绕 +Z **顺时针**旋转（从 +Z 看），`fold_sign = -1`。

因此两个关节都能各自独立走完 0°～180°。同时折叠时，第 2 节向 +Y 翻到第 1 节上方，第 3 节再向 -Y（第 2 节局部坐标）翻到第 2 节下方；在世界坐标中三节形成并排的三层，主体之间保留约 0.6 mm 间隙，不发生干涉。

运动学变换（列向量，右乘先作用）：

```text
part_1: I
part_2: Rz(+a1, J1)
part_3: Rz(+a1, J1) * Rz(-a2, J2)
```

其中 `J1=(0,6.3,0)`、`J2=(40.5,-6.3,0)` 是 0°姿态下的世界坐标；`a1,a2 ∈ [0,180]`。关节 2 的轴线随第 2 节一起运动，`joints.json` 中有明确说明。

## 5. 打印方向与参数

**打印方向：直接把 `model.stl` 按导出姿态放到打印平台，不需要旋转。**

- STL 的 Z=0 平面就是平台接触面；模型平放，厚度方向沿 Z，销轴/轴孔都是竖直的。
- 这样销轴、轴孔和沉孔都沿打印层方向成形，关节间隙内不需要支撑。
- 材料：PLA；喷嘴 0.4 mm；层高 0.2 mm；2 圈外墙；15% 网格填充；PLA 220 °C / 热床 55 °C。
- 使用 `/opt/slicer/p1s_pla_0.20mm_nosupport.ini`（support_material = 0）。
- 一次打印 `model.stl`，不要分别打印三个零件后再组装；`parts/*.stl` 只用于运动验证。
- 导入时保持三个壳体在同一个对象内；不要使用“拆分零件”或自动排列功能，否则会破坏装配位置。
- 如平台附着力不足，可在模型外围加 3–5 mm brim；brim 不得进入关节间隙。

打印后无需安装销轴、螺丝或任何其他零件。第一次活动关节时，如有少量拉丝/桥接毛边，可轻轻来回转动使其松脱；不要沿 Z 向强拉。

## 6. 实际几何检查

已完成以下检查：

1. **OpenSCAD 渲染**：`openscad -o model.stl model.scad` 成功；CGAL 报告 `Simple: yes`。
2. **网格完整性**：`prusa-slicer --info model.stl` 报告
   - `manifold = yes`
   - `number_of_parts = 3`
   - 尺寸 `121.0 × 18.6 × 5.0 mm`
   - 体积约 `7277.05 mm³`
3. **单件 STL**：`parts_1/2/3.stl` 均为 watertight、单连通体；三件体积之和与 `model.stl` 完全一致（误差 < 1e-9 mm³），包围盒并集与 `model.stl` 一致。
4. **静态最小间隙**：0°时对不同零件的表面采样，最小间隙约 **0.3997 mm**，位于转动环与让位孔之间；主体端面间隙 0.5 mm，挡环与沉孔径向间隙 0.6 mm。
5. **运动干涉检查**：在关节 1、关节 2 均为 0°～180°、步长 2°的 **8281 个姿态**上，用 `trimesh + manifold3d` 做三对零件的布尔相交检查；所有姿态的最大相交体积为 **0 mm³**。结果见 `collision_check.json`。`validate_motion.py` 可复现该检查（默认步长 5°，可用 `--step 2` 复现本次结果）。
6. **轴向防脱检查**：把第 2 节单独沿 Z 平移 ±0.5 mm 时，它与第 1/3 节的相交体积分别为 0.93/1.63 mm³（向下）和 1.63/0.93 mm³（向上）；±0.4 mm 为设计轴向间隙，再往外即被上下挡环挡住，不能沿轴向脱出。

## 7. 实际切片检查

使用 PrusaSlicer 2.7.2 和 0.4 mm 喷嘴、0.2 mm 层高、PLA、无支撑配置切片：

```bash
prusa-slicer --export-gcode \
  --load /opt/slicer/p1s_pla_0.20mm_nosupport.ini \
  --output /tmp/model_nosupport.gcode --dont-arrange model.stl
```

实际结果：

- 切片成功，共 **25 层**（0.2–5.0 mm），无 `;TYPE:SUPPORT` 路径。
- 预估打印时间约 **33 分 37 秒**，耗材约 **4.13 cm³**（1.75 mm PLA 约 1715.96 mm）。
- 关节间隙内没有支撑材料；三个零件从第一层起就是分离的，只在销轴/捕获孔处互相咬合。
- 另用自动支撑配置 (`p1s_pla_0.20mm_autosupport.ini`) 复核，G-code 中同样没有生成任何 `;TYPE:SUPPORT` 路径。
- 切片器给出的通用稳定性提示为 `Floating bridge anchors, Loose extrusions`。它对应关节内两处短环形桥接面（G-code 中 z≈1.6 mm 和 z≈4.2 mm 的 `Overhang perimeter`/`Bridge infill`），是捕获板/挡环的约 1.0–1.9 mm 短桥接，不是关节间隙内的支撑。桥接区均与同一零件主体连续相连，0.4 mm 轴向间隙足以避免与另一零件融合。
- 为获得最好的桥接质量，建议：第一层正常速度，桥接风扇全开；不要开启“支撑优先”或自动支撑，以免支撑进入 0.4–0.5 mm 的活动间隙。

## 8. 复现命令

```bash
cd /app/output
openscad -o model.stl model.scad
# 单件导出：临时把 PART_SELECT 改为 1/2/3 后渲染
# parts_1/2/3.stl 已按同一坐标导出

python3 validate_motion.py --step 5
prusa-slicer --export-gcode \
  --load /opt/slicer/p1s_pla_0.20mm_nosupport.ini \
  --output /tmp/model_nosupport.gcode --dont-arrange model.stl
```
