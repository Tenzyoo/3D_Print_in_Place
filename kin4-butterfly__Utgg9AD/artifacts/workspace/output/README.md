# 可动蝴蝶（一体打印）：打印方向与检查说明

## 文件
| 文件 | 内容 |
|---|---|
| `model.scad` | 参数化源码。`part=0/1/2/3` 分别输出整体/躯干/左翅/右翅，`angle_L`、`angle_R` 可设置翅膀转角 |
| `model.stl` | 中立姿态整体模型（3 个互不相交的实体） |
| `parts/parts_1.stl` | 躯干，固定件（头、复眼、触角、胸、腹，以及 2 根带防脱帽的销轴） |
| `parts/parts_2.stl` | 左翅（+Y 侧），含轴孔环 |
| `parts/parts_3.stl` | 右翅（−Y 侧），含轴孔环 |
| `joints.json` | 零件、2 个转动关节（轴线、原点、范围 −30°…+30°） |
| `verify_geometry.py` → `verification_report.json` | 几何／运动检查 |
| `slice_check.py` → `slice_report.json` | PrusaSlicer 切片检查 |
| `joint_section.png`、`preview_iso.png`、`preview_motion_pm30.png` | X=0 关节剖面、外观图、±30° 两极限姿态叠加图 |

坐标系：X 为躯干纵向（头朝 +X），Y 为翼展方向（左 = +Y），Z 竖直向上。单位 mm。

## 关节结构（每侧一个，轴线平行 Z）
- 销轴属于躯干：Ø5 轴身。底部是 45° 锥形法兰（最大 Ø8），顶部是 45° 倒锥防脱帽（Ø15），防脱帽再与胸部相连。
- 翅膀根部是 Ø14 × 5 mm 的孔环，孔径 Ø6，**单侧径向间隙 0.5 mm**。孔底做了 45° 倒角，与法兰配合。
- 所有相邻活动面都由 `offset(r=0.5)` 生成，法向间隙处处为 0.5 mm。孔环外壁与躯干之间的径向间隙也是 0.5 mm。孔环上方，躯干留出的空腔是 45° 尖顶形。
- 轴向防脱：翅膀向上约 0.85 mm 就会碰到防脱帽，向下约 0.75 mm 就会碰到法兰，无法沿轴线脱出。
- 两个关节互相独立，各自的旋转只受翅膀与躯干外形的限制。

## 打印方向与设置
- **按模型原样摆放**：Z 轴朝上，底面 z=0 整体贴床，不需要旋转。两片翅膀平铺在热床上（翼板厚 2 mm，叶脉、边框、眼斑凸起 0.6 mm），销轴竖直打印。
- PLA，0.4 mm 喷嘴，0.2 mm 层高，使用 `/opt/slicer/p1s_pla_0.20mm_nosupport.ini`（**不加支撑**）。
- **不要加 brim**：实测 5 mm brim 的走线距关节轴 7.17 mm，正好落在孔环（r=7）与躯干（r=7.5）之间的 0.5 mm 间隙里，会把首层粘连。若担心附着力，请用胶水或 PEI 板。
- 打印后，用手指把每片翅膀先来回轻轻掰动，使首层的轻微象脚分离。

## 实际完成的检查
**几何检查**（`verify_geometry.py`，trimesh + manifold3d）
- 3 个零件 STL 都是水密、法向一致的单一连通体；`model.stl` 体积 = 三个零件体积之和（18156.6 mm³）。
- 中立姿态外接尺寸 **105.99 × 98.60 × 14.79 mm**（≤ 120 × 100 × 30）。
- 在轴身截面（z = 2.5 / 3.5 / 4.5）实测销轴半径 2.500、孔半径 3.000，径向间隙为 **0.499–0.501 mm**。
- 运动检查共 85 种姿态组合：
  - 一片翅膀在 −30…+30°（步长 5°）内转动，另一片固定在 −30 / 0 / +30°；
  - 两片翅膀同时运动的 7×7 全网格（步长 10°）。
  
  三对零件（躯干-左翅、躯干-右翅、左翅-右翅）的布尔相交体积均为 **0**，最小间隙 **0.498 mm**（出现在关节处）。离开关节区以后，翅膀与躯干的间隙 ≥ 4.16 mm。
- 首次接触角（另一翅保持中立）：左翅 +42° / −35°，右翅 +35° / −42°。要求的 ±30° 全程无干涉，两个方向都还有至少 5° 余量。
- 超过 45° 的悬垂面积：三个零件均为 0 mm²。关节处所有间隙面都是竖直面或 45° 自支撑锥面。

**切片检查**（`slice_check.py`，PrusaSlicer 2.7）
- 整体模型用无支撑配置切片成功：74 层，约 2 h 01 min，耗材 13.1 cm³（约 16 g）。
- 用自动支撑配置切片：**生成的支撑为 0**，关节区内当然也没有支撑。
- 把 3 个零件按真实相对位置分别切片，逐层解析 G-code：
  - 关节附近躯干与翅膀线材之间的最小水平间隙为 **0.47 mm**（已扣除线宽，共 25 层）；
  - 不同零件在 XY 上重叠的线材，最小竖直距离为 0.8 mm，即中间至少隔 3 个空层，不存在直接叠打而粘连的情况。
- 关节区内的 bridge infill 都是零件内部的实心层；唯一的悬空桥接是 z=8.0 处躯干内部空腔尖顶的封口，下方距孔环约 3 mm，不会碰到翅膀。
- 遗留提示：无支撑配置会报 PrusaSlicer 的启发式警告 "Low bed adhesion"。逐个特征排查后确认，触发源是圆润的腹部节段（首层接触面小）。这不是支撑问题：自动支撑配置判定无需任何支撑。关闭该警告只能靠 brim，而 brim 会粘连关节（见上），所以保持不加 brim。

重新生成：`openscad -o parts/parts_N.stl -D part=N model.scad`（N=1..3），`openscad -o model.stl model.scad`，然后运行 `python3 verify_geometry.py` 和 `python3 slice_check.py`。
