# 一体打印可活动小蛇 — 打印方向与检查说明

## 文件
| 文件 | 内容 |
|---|---|
| `model.scad` | 参数化源码（`-D part=0` 整体，`-D part=1..6` 单个零件） |
| `model.stl` | 中立伸直姿态整体模型（6 个独立实体） |
| `parts/parts_1.stl` … `parts_6.stl` | 1 = 头部，2–6 = 身体段 1–5（6 为尾尖段），与 `model.stl` 同一坐标系 |
| `joints.json` | 零件、关节（父/子零件、旋转轴、位置、运动范围、随动零件、间隙） |
| `build.sh` | 一键重新生成全部 STL / joints.json 并重跑所有检查 |
| `checks/` | 检查脚本、检查报告（`geometry_report.txt`、`gcode_gap_report.txt`）、预览图 |

## 结构
- 头部朝 +X，尾尖在 x = 0，Y 对称，底面 z = 0。5 个关节轴均为 Z 轴，位于 x = 121.6 / 99.6 / 77.6 / 55.6 / 33.6 mm，y = 0。
- 关节 k 的前方零件 k 带 **C 形轴座环**（外径 19.2 mm），后方零件 k+1 带 **竖直销轴**（R 5.5 mm），销轴经 4 mm 宽的颈部连到身体。
- **轴向防脱**：销轴中部有一圈 60° 双锥凸环（R 6.7 mm），轴孔内有与之偏移 0.5 mm 的同形凹槽，所以销轴向上、向下都无法退出（轴向窜动仅 0.87 mm）。轴座包角大于 180°，凸环比开口宽，径向也拉不出来。
- **限位**：颈部按 ±34° 扫掠范围（另加 0.5 mm 间隙）在轴座上开口，转到约 ±37° 时颈部碰到开口边缘，形成硬限位。身体段前端做成 ±55° 楔形加凹弧，转到限位时也不会碰到前段。
- 间隙：销轴与轴孔单侧径向间隙 0.5 mm（实测 0.497–0.499 mm，差值来自多边形离散）；锥面法向间隙 0.43 mm；轴座环与后段身体之间 0.6 mm；颈部与开口之间至少 0.5 mm。

## 打印方向与建议设置
- **平放打印**：模型原样导入，底面 z = 0 贴床，Z 向上（即关节轴竖直），无需旋转。
- PLA，0.4 mm 喷嘴，0.2 mm 层高，**不开支撑**，不加 brim（brim 可能把相邻零件的底边连在一起）。
- 关节内所有面都是竖直面，或与水平面成 60° 的锥面，不存在需要支撑或跨越间隙架桥的面。
- 打印后掰动每节，使首层可能存在的轻微粘连断开。如果首层压得偏扁，可在切片软件里设置 elephant foot compensation ≈ 0.1–0.15 mm。

## 实际完成的检查（结果见 `checks/*.txt`）
**几何（`checks/verify_geometry.py`，trimesh + manifold3d）**
1. 6 个零件都是水密、流形的单一实体；`model.stl` 有 6 个实体，体积与各零件之和一致（25482 mm³）。
2. 外形尺寸 149.6 × 25.0 × 14.5 mm，未超过 160 × 50 × 40 mm 的上限。
3. 中立姿态下，任意两个零件之间布尔相交体积为 0，相邻零件最小间隙 0.431 mm（出现在锥面法向）。
4. 在 7 个高度上取截面实测径向间隙：0.497–0.499 mm。
5. 运动扫描：按 joints.json，对每个关节把其子链（零件 k+1…6）在 −30°…+30° 内以 1° 步长旋转，均无干涉，最小间隙 0.431 mm。实测首次接触（硬限位）在 ±37.1°。三种组合姿态（5 个关节同时 +30°、同时 −30°、交替 ±30°）下任意零件两两之间也无干涉。
6. 防脱：把子链沿 +Z / −Z 平移 0.88 mm、沿 −X 拉出方向平移 0.96 mm、沿 +Y 平移 0.52 mm 后，就与父零件实体相交，说明不能沿轴线或径向直接脱出。
7. 悬垂：各零件朝下面与竖直方向的夹角最大为 30°（锥面）。比 45° 更陡的面积约为 0（只有头部有面积极小的三角形碎片，四舍五入为 0.00 mm²）。

**切片（PrusaSlicer 2.7.2，`/opt/slicer` 的 P1S 配置）**
1. 无支撑配置切片成功：72 层，预计打印 1 h 36 min，耗料约 5.5 m（约 16.5 g PLA）。
2. 用**自动支撑**配置切片，生成的支撑挤出段数为 **0**，说明切片软件判断全模型无需支撑。
3. `checks/verify_gcode_gaps.py` 逐层解析 G-code：把每条挤出线按其实际线宽展开，归属到对应零件，再测量相邻零件挤出线之间的最小距离。全部 72 层中每个关节都 ≥ 0.449 mm，首层为 0.477–0.483 mm，没有任何一层发生融合。
4. G-code 中的 796 段桥接都在 z = 11.2 / 13.2 mm，处于零件内部稀疏填充之上的顶面下方，全部落在同一零件自身的材料上方；没有任何桥接或支撑跨越关节间隙。

未做实物打印测试；以上结论均来自几何计算与切片结果。
