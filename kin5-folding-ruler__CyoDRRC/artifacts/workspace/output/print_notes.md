# 打印方向与检查记录

## 打印方向

- 将三节尺的平面放在打印平台上，模型坐标 `Z=0` 面朝下；长轴沿 `X` 方向。
- 使用 PLA、0.4 mm 喷嘴、0.2 mm 层高。切片配置为 `/opt/slicer/p1s_pla_0.20mm_nosupport.ini`。
- 支撑关闭，使用 3 mm brim。未加 brim 时切片器提示总装床面附着面积偏小；加 brim 后切片成功且没有支撑、悬空或稳定性告警。
- 销臂位于 `Z=2.0..3.2 mm`，轴孔环位于 `Z=0..1.6 mm`，两者轴向净空为 0.4 mm。销臂由尺段主体和从打印平面长出的销轴两端承托，活动间隙不使用支撑材料。

## 几何检查

- OpenSCAD 2021.01 完成 CGAL 网格导出；总装 STL 为 watertight/manifold，包含 3 个独立连通部件。
- PrusaSlicer `--info` 报告 3 个部件，尺寸为 `120.8 x 32.8 x 5.0 mm`。三份单件 STL 的体积和与总装 STL 体积差小于 `1e-9 mm^3`；单件 STL 保留总装坐标和展开姿态。
- 两个关节均为 Z 轴销轴关节。销半径 1.5 mm、孔半径 2.0 mm，单侧径向间隙 0.5 mm；销帽与轴孔环的轴向间隙 0.6 mm。主体端部之间留 0.4 mm 间隙。
- 使用三份独立 STL 对 `0..180` 度以 5 度步进遍历了两个关节的 1,369 种角度组合，并对每种组合的三个部件对进行实体布尔交集检查，共 4,107 次。采样状态中最大交集体积为 0 mm^3。此结果是离散角度采样，不构成所有实数角度的连续碰撞证明，也不是实体打印后的耐久/活动测试。

## 轴向保持说明

销帽可阻止轴孔环沿 `+Z` 脱出。当前打印姿态下轴孔环的下表面与平台齐平，销轴底端没有高于平台的扩大止挡；脱离平台后，轴孔环仍可能沿 `-Z` 越过销轴底端。若需要双向机械防脱，需增加底部止挡并重新解决其与平台首层及轴孔环的打印间隙。
